# Codex-only Brainstorming

> M01 foundation contract. This namespace is not selected by root routing before M04.

Classification: **carry over**.

## Ownership

This module owns exploratory scope formation for projects that select `codex_only`: tentative options, durable scope/revision identity, research questions and readiness for Project Definition.

## Invariants

- Brainstorming is not accepted product/system authority.
- Research may inform options but does not promote them into accepted decisions.
- The first promotion from exploration into Project Definition remains an explicit user-owned gate.
- A coordinating Codex context may organize the exploration, but runtime worker identity is not project authority.
- Durable repository state, not transcript history, is the recovery source.

## Continuation

When the exact exploratory subject is user-authorized for Definition, route to the policy-local Definition owner. Otherwise continue Brainstorming/Research or stop only for a real user decision.

M04 reconciles the full routing/recovery wording before this namespace becomes active.
