# Codex-only Independent Plan Review

> M01 foundation contract. This namespace is not selected by root routing before M04.

Classification: **adapt**.

## Foundation contract

- Review one exact immutable plan subject against the approved Definition and accepted decisions.
- The reviewer is independent from the plan implementation/authoring owner for that exact subject.
- Review does not mutate the subject while judging it.
- Persist a durable GREEN/RED verdict and concise evidence.
- RED routes to Planning, Project Definition or Research according to the defect; reviewer role does not silently rewrite accepted authority.
- A qualifying Codex-managed reviewer satisfies the project gate without an additional mandatory normal-ChatGPT review.

M02 defines the final project-level review provenance/state representation while keeping runtime reviewer lifecycle outside Project Workflow.
