# Codex-only Research

> M01 foundation contract. This namespace is not selected by root routing before M04.

Classification: **carry over**.

## Ownership

Research produces evidence for an exact project question and a durable return target. It does not create accepted product/system authority by itself.

## Durable semantics

A research obligation records enough project-level information to recover:
- lifecycle status;
- origin role and exact origin subject;
- question/scope;
- exact return target;
- result/evidence;
- return-reconciliation state.

The concrete Investigator/worker realization belongs to `codex_workflow`; Project Workflow records the research obligation and result, not runtime lifecycle identity.

Completed research returns to its exact owning project role for reconciliation before the obligation is consumed. M04 reconciles the complete policy-local Research routing before activation.
