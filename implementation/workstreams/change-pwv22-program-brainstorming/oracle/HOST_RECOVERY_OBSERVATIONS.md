# Host/recovery observation requirements

This corpus is independent scenario authority derived from R7 plus accepted R6 failure families. R6 P0–P6 is architecture evidence only; its historical GREEN does not satisfy future package/host/recovery acceptance.

## Retention/deletion boundary
Retain only canonical native Git state, published semantic contracts and exact native evidence needed to locate already-published work. Delete chat memory, runtime/session state, helper-local caches/correlation and disposable projections. Concrete native persistence paths remain intentionally deferred to S17. Destructive operations are disposable-fixture-only.

## Actual versus synthetic
Every case has an independent expected semantic outcome. Synthetic checks may validate shape/mutants now. Cases with `actual_required` MUST later receive positive installed-host evidence; a simulated Pi response or historical R6 observation cannot substitute. Required hosts are ChatGPT and installed Pi/Paseo. All four transfer directions are explicit.

Installed package resolution must prove exact official provenance/compatibility; absent/incompatible/tampered package falls back to canonical Git and never to “latest”. Remote-published commit is continuation truth; local-only state is rejected. One active same-branch slot is enforced and superseded slots are disposed only after remote readback.

Legacy v1/v2.0/v2.1 inputs are snapshotted before/after and must remain byte-identical with zero canonical writes. Reconstruction compares independently expected legal continuation before/after deletion, not a production router's self-report.

P7 is absent because no hard-prevention authority exists.
