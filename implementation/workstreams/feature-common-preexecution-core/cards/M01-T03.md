### Must preserve

- One runtime-neutral semantic core at target `workflow/`; no fixed ChatGPT/Codex policy semantic trees.
- No canonical `execution_policy`, runtime/model/session/worker identity, durable orchestration binding, universal `active_execution`, ordinary `returned`/`transfer_ready`, Project-Card scheduler/batch/lane state or Context Health lifecycle.
- One Project Workflow Card may execute at a time per selected workstream; runtime-internal workers never become competing shared-state owners.
- Main/coordinator is sole shared-state reconciler.
- Manifest owns workstream identity/routing; selected Task Board owns mutable Card/milestone execution state; stable Cards remain contracts only.
- Exact refs and bindings fail closed on wrong workstream/branch/class/path.
- Review provenance is semantic and exact-subject based; concrete runtime identity is non-canonical.
- External-effect evidence is obligation-local; do not create a universal event ledger.
- Schemas/templates are minimal, owner-driven and extensible only when later concrete transitions require fields.

### Must not / rationale that must travel

- Do not recreate V1 state schema wholesale.
- Do not create a mutable global workstream registry or second project-control database.
- Do not make all future milestone fields mandatory now.
- Do not create speculative migration compatibility fields in normal V2 state.
- Do not let fixtures become selectable live state.
