## Must preserve
- every unique knowable recovery artifact is in the final merge subject before merge;
- post-merge closure recovers from target-side package + immutable PR/merge evidence even if the source head was auto-deleted immediately;
- original branch/base/parent provenance is preserved and the source ref is never recreated for bookkeeping;
- surviving branch cleanup uses minimal safe_to_delete only when needed, exact current-head revalidation before deletion and absence readback afterward;
- terminal unmerged/superseded closure preserves recovery-only metadata without importing rejected implementation content.

## Outcome
Completed work remains recoverable and cleanup-safe after immediate source-branch disappearance, surviving-head movement, or intentional terminal-unmerged closure.

## Included scope
- target-side terminal-package/recovery contract;
- source-ref-independent closure validation;
- safe-to-delete lifecycle helper semantics;
- immediate deletion, surviving-head movement, absence readback and terminal-unmerged fixtures.

## Excluded scope
- performing real branch deletion;
- external tracker effect semantics already owned by T02;
- fork lineage rules (T04).

## Acceptance
- terminal recovery succeeds with no source ref when exact target package + immutable merge evidence are present;
- missing unique pre-merge artifact fails closed;
- stale safe_to_delete head forbids deletion;
- absence readback is required before recording deleted;
- terminal-unmerged closure preserves history without merging rejected content.

## Required verification
- A10 deterministic fixtures and recovery/router checks;
- immediate auto-delete and surviving-head-movement cases;
- sh scripts/test.sh;
- exact GitHub readback.
