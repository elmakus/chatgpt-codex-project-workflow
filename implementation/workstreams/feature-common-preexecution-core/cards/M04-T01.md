## Must preserve

- refresh current target before first final-review freeze/reuse and immediately before a movable integration mutation;
- target SHA/ancestry movement alone never invalidates GREEN when exact covered content/behavior/acceptance is unchanged and affected compatibility is GREEN;

## Outcome

The common Close/integration contract can refresh a moving target, distinguish ancestry-only movement from material semantic change, and preserve or invalidate review coverage correctly.

- semantic conflict fails closed even when textual integration is clean;
- target movement between refresh and mutation forces refresh repetition;
