## Must preserve

- exactly one Project Workflow Card may execute in the selected workstream;
- runtime may use zero, one or many internal workers sequentially or concurrently inside that Card;
- qualifying delegation is based on available capability + bounded authority/context + valid return path, not a persisted runtime identity;
- when qualifying delegation exists, Main delegates substantive implementation/debugging/testing while retaining routing, state ownership, authority interpretation, validation and reconciliation;
- internal workers may not mutate shared Task Board/manifest or create Project Cards;
- Main normalizes/validates worker output before persisting canonical result;
- a bad result with valid contract stays in progress for correction; only a real unresolved blocker becomes blocked;
- no-delegation runtime uses the same common semantic contract directly.

## Dependencies

- M03-T01 done.

## Outcome

The production state/router contracts represent runtime-neutral Card execution and delegated-result reconciliation while preserving Main as sole semantic state writer.

## Included scope

- one-in-progress-Card validation;
- capability-neutral delegated/direct execution route representation;
- worker result/evidence return contract without worker/session/model IDs in canonical state;
- Main-only result reconciliation;
- internal sequential/parallel worker semantics inside one active Card;
- bad-result correction versus real blocker distinction;
- deterministic A04/A05-oriented fixtures, including multiple internal workers with one Card and no-delegation fallback.

## Excluded scope

- concrete Codex worker invocation schema;
- Pi subagent extension/package;
- scheduler/Project-Card parallelism;
- exact independent-review attempt lifecycle (T03);
- full RED/recovery classification (T04).

## Acceptance

- two Project Cards in progress fail closed, while one Card can record evidence produced by multiple internal workers without extra Cards;
- canonical state contains semantic result/evidence only, not runtime worker/session/model identity;
- qualifying delegation and direct fallback reach the same semantic result contract;
- Main alone performs durable state transition after validating returned evidence;
- already durable valid result is recognizable for later no-replay recovery.
