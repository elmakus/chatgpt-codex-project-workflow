## Must preserve

- REQUIRED and activated RECOMMENDED are real blocking gates until exact current subject is GREEN;
- review subject identifies exact immutable content plus acceptance identity;
- independence is semantic: a producer/repairer of the exact subject cannot independently review it;
- changed implementation creates a new attempt/subject; completed RED/GREEN history stays immutable;
- capability-first internal independent context is legal when it genuinely did not produce the subject;
- when current context produced the subject and no qualifying independent context exists, freeze pending subject and emit only locator-style fresh-context continuation;
- Stage-6 Plan Review remains a separate premium exception and is not folded into common implementation review;
- concrete reviewer model/session identity is not canonical PW state.

## Dependencies

- M03-T02 done.

## Outcome

V2 has a common exact-subject implementation review lifecycle with append-only attempts, semantic independence and correct capability-first/fresh-context routing.

## Included scope

- review attempt template/state validation;
- pending/in-progress/GREEN/RED lifecycle;
- exact subject + acceptance-surface binding;
- semantic provenance sufficient to reject self-review without runtime telemetry;
- changed-subject/new-attempt behavior;
- capability-first versus fresh-context continuation semantics;
- deterministic A07 and stale/invalid-independence fixtures.

## Excluded scope

- final target integration refresh/coverage reuse (M04);
- premium Stage-6 Plan Review changes;
- runtime-specific reviewer launcher.

## Acceptance

- producer/repairer cannot issue independent verdict for its exact subject;
- terminal verdict requires durable evidence and never mutates into another subject;
- changed subject requires a new attempt while old verdict remains;
- pending REQUIRED/RECOMMENDED blocks terminal Card completion;
- GREEN returns to deterministic Card finalization rather than creating an artificial stop;
- RED can return to deterministic correction classification rather than becoming a verdict-only stop.

## Required verification

- A07 production-state/router fixtures;
- invalid semantic-independence and stale-subject negative fixtures;
- internal-independent-context and fresh-context route fixtures;
- `sh scripts/test.sh`;
- exact GitHub readback.
