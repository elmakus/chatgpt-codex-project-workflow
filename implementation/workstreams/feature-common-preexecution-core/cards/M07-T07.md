## Outcome
Prove actual V2 N-CHATGPT topology using two genuinely fresh top-level ChatGPT contexts:
- first fresh context independently reviews S1;
- after RED, the same first context performs the bounded correction under the same Card and freezes S2;
- because that context materially repaired S2, it stops only for the fresh independent review obligation;
- second fresh context independently reviews exact S2;
- after GREEN, the same second context finalizes the Card without a verdict-only stop.

## Included scope
- clean GitHub-backed V2 fixture with one active Card;

- exact immutable review subjects and append-only attempt history;

- Main-only Project Workflow state reconciliation;
- exact readback after each user-driven context.

## Acceptance
GREEN requires:
- context 1 starts fresh from pending S1 review;
- S1 receives independent RED;
- RED does not cause an artificial user stop;
- context 1 corrects under the same Card and freezes exact S2;
- context 1 stops because it cannot independently review the subject it materially repaired;
- context 2 is a genuinely fresh ChatGPT context;
- context 2 independently GREENs exact S2;
- GREEN does not cause a verdict-only user stop;
- context 2 finalizes the same Card and continues until the next real workflow stop;
- exact S1/S2 subjects, review history, Task Board transitions and final bytes validate against the pinned candidate;
- no runtime/model/session identity enters canonical Project Workflow state.
