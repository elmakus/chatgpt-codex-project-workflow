# M04-T02 — External effects and final tracker lifecycle

Milestone: `M04 — Integration, tracker closure, publication and terminal recovery`
Target implementation: `elmakus/project_workflow_v2@feat/pwv2-m04-integration-close`
Depends on: M04-T01
Review requirement: none (covered by cumulative M04 acceptance/review in M04-T05)

## Authority

- `PWV2-P1` M04.P2.
- `requirements/PROJECT_WORKFLOW_V2.md` R1: PWV2-REQ-032..033, 056..060, 066.
- ADR-PWV2-003.
- accepted M04-T01 result and M02 tracker model.

## Must preserve

- meaningful external mutation uses WRITE/ACTION → READBACK → VERIFY EXPECTED STATE → EVIDENCE;
- ambiguous timeout/unknown occurrence requires exact-object inspection before retry and fails closed if occurrence remains uncertain;
- intermediate PR/commit linkage must not close the tracker;
- only the final accepted scope-completing default-branch integration may use closing linkage;
- post-completion Issue state is read back; explicit close is allowed only after durable accepted completion when automatic closure is unavailable;
- Issue state remains bookkeeping, never implementation authorization.

## Outcome

V2 has an idempotent external-effect contract and a safe final GitHub Issue lifecycle that cannot duplicate uncertain mutations or close accepted scope early.

## Included scope

- external-effect state/evidence validation and retry decision helper;
- tracker closing-linkage decision contract;
- post-merge expected Issue-state verification;
- interrupted-write, unexpected-closure and final/intermediate linkage fixtures.

## Excluded scope

- real Issue mutation during deterministic tests;
- target-side branch-deletion recovery (T03);
- fork publication (T04).

## Acceptance

- ambiguous external write cannot be blindly retried;
- verified no-effect may retry, verified effect reconciles without duplicate action;
- intermediate integration cannot select closing linkage;
- final accepted default-branch completion can select closing linkage and requires readback;
- unexpected early closure routes reconciliation rather than approval.

## Required verification

- A06 and L03-ready deterministic oracles;
- interrupted write/readback fixtures;
- tracker lifecycle fixtures;
- `sh scripts/test.sh`;
- exact GitHub readback.
