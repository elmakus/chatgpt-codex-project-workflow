# M05-T03 — Semantic package update propagation and readback

Milestone: `M05 — Thin ChatGPT/Codex delivery with verified update propagation`
Target implementation: `elmakus/project_workflow_v2@feat/pwv2-m05-delivery`
Depends on: M05-T02
Review requirement: none (covered by cumulative M05 acceptance/review in M05-T05)

## Authority
- `PWV2-P1` M05.P3 and M05 JIT.
- `requirements/PROJECT_WORKFLOW_V2.md` R1: PWV2-REQ-008..015, 016, 069.
- ADR-PWV2-002 and ADR-PWV2-006.
- accepted M05-T02 package result.
- supported external installer/update mechanism as discovered from current durable/package evidence; do not freeze old V1 commands.

## Must preserve
- semantic update changes canonical `workflow/` authority without requiring unrelated Skill/hook/bootstrap edits;
- update uses the supported external installer rather than a project patch pin, update daemon or alternate semantic route;
- fresh installed session reads back updated bundled module bytes/observable behavior from one unambiguous source;
- source/version/hash evidence belongs to package-test evidence, not canonical project execution state;
- compatible update preserves existing durable obligations and immutable review subjects;
- ordinary entry never fetches remote workflow policy.

## Outcome
An isolated candidate package proves that a canonical semantic edit propagates through the supported plugin update path and is observable after fresh installed entry.

## Included scope
- isolated candidate distribution/package;
- one harmless observable canonical-module change for propagation proof;
- pre/post package/hash/source readback;
- supported installer/update invocation discovered JIT;
- fresh-session installed-module/behavior readback;
- unaffected bootstrap hash/control check.

## Excluded scope
- production project adoption;
- permanent update service/daemon;
- per-project exact patch pin;
- migration/custody transfer.

## Acceptance
- canonical semantic change is present after supported package update and fresh entry;
- Skill/hook/bootstrap bytes remain unchanged unless the test intentionally exercises their behavior;
- installed source is unambiguous and locally bundled;
- no durable project state conversion or review-subject mutation occurs due only to package update.

## Required verification
- deterministic package/hash/source tests;
- L05-ready propagation evidence;
- `sh scripts/test.sh`;
- exact candidate/source/readback evidence.
