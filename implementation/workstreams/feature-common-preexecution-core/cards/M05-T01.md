- `planning/PROJECT_WORKFLOW_V2_MASTER_PLAN.md` revision `PWV2-P1`, M05.P1 and M05 JIT.

## Must preserve
- ChatGPT obtains V2 authority from the V2 GitHub repository through user-owned Project Instructions/bootstrap.
- Bootstrap remains thin: repository/contract locator -> common router -> exact current module/state/authority.
- No copied semantic policy tree, second project/state store, runtime identity, Context Health/FRESH lifecycle or exact per-project workflow patch pin.
- Fresh-context handoff is locator-only and contains only project/branch/entry obligation/durable pointer needed for recovery.
- Ordinary semantic changes must not require bootstrap edits unless bootstrap behavior itself changed.

## Outcome
A minimal ChatGPT delivery surface enters the canonical V2 router and supports exact durable recovery without duplicating workflow semantics.

## Included scope
- user-owned Project Instructions/bootstrap template for V2;
- locator-only fresh-session prompt/template;
- optional minimal start convenience only if it adds current value;
- deterministic tests/read-set assertions proving progressive disclosure and absence of copied policy.

## Excluded scope
- Codex plugin packaging (T02);
- installed-plugin update propagation (T03);
- real Android/Codex surface execution (T04);
- V1 migration/adoption/custody transfer.

## Acceptance
- bootstrap points to the V2 repository/common router and recovers exact consumer repo/workstream state;
- fresh handoff is locator-only and does not copy workflow narrative/evidence;
- no second semantic/state copy or runtime-specific workflow authority is introduced;
- ordinary canonical workflow edits remain independent of bootstrap bytes.

## Required verification
- A01/A02/A17 foundations applicable to ChatGPT bootstrap/read sets;
- deterministic bootstrap/content tests;
- `sh scripts/test.sh`;
- exact target commit/PR/Actions readback.
