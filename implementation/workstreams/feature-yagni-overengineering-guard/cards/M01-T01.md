### Must preserve

- One canonical full YAGNI/proportional-design invariant lives in policy-neutral common authority; policy-local consumers reference/apply it rather than maintaining divergent copies.
- Prefer the least unnecessary complexity that still satisfies the complete current accepted requirements, decisions, constraints, invariants and verified evidence.
- Do not add speculative abstraction, generality, extensibility, configuration, dependencies, infrastructure, compatibility paths or future-proofing solely for hypothetical future needs.
- Every material complexity increase has a concrete current justification traceable to accepted authority, verified evidence, an existing current contract/constraint or demonstrated current reuse/variation.
- YAGNI never weakens current correctness, security, testing, maintainability/refactoring, compatibility, observability, migration or other applicable quality obligations.
- “Simplest” means least unnecessary complexity, not minimum lines/files/effort.
- Prefer an existing fitting mechanism when adequate, while allowing new machinery when current authority/evidence actually requires it.
- Generalize from demonstrated current shared need/variation or another current constraint; temporary duplication may be preferable to a premature/wrong abstraction.
- Keep the accepted change focused; unrelated cleanup is excluded unless required by the current obligation.
- Do not add a YAGNI-specific phase, state owner, gate, score/budget, registry or numeric abstraction threshold.
- Both migrated fixed-policy routers continue to bootstrap the same `workflow/common/AUTHORITY.md`.
- Existing ChatGPT-only and Codex-only OpenSpec ownership remains unchanged.

### Must not / rationale that must travel

Do not build a YAGNI subsystem, complexity scoring engine, policy-specific duplicate definitions, mandatory OpenSpec ceremony, or unrelated workflow cleanup. The feature is one shared invariant plus the minimum operational Planning/Review references, tests and discoverability needed to make it effective.
