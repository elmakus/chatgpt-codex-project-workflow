### Must preserve

- legacy Codex/shared contracts are evidence inventory only, not the architectural base;
- Project Workflow owns project authority/state while `codex_workflow` owns worker/runtime mechanics;
- useful legacy behavior must receive an explicit preserve/adapt/reject disposition so it cannot disappear silently;
- this repository remains `execution_policy: chatgpt_only`;
- root routing must not be cut over by this Card.

## Outcome

A durable, auditable baseline matrix exists that enumerates every current ChatGPT-only policy-local module/template and the relevant legacy Codex/shared routing/execution contracts, classifies their target treatment, and records preserve/adapt/reject dispositions for the useful legacy properties required by `CO-REQ-026`.

## Scope

### Included

- inventory every file currently under `workflow/chatgpt_only/`;
- map each file to a future `workflow/codex_only/` owner or a deliberately policy-neutral common owner;
- classify each item as lifecycle-semantic carryover, Codex-specific adaptation, genuinely-common candidate, or not-applicable;
- inventory relevant legacy evidence from `workflow/codex/*`, shared top-level execution/planning/review contracts, `workflow/contracts/*`, and `workflow/legacy/CONTEXT_ROUTING.md`;
- explicitly disposition the useful legacy properties named by `CO-REQ-026`: Codex Main accountability, continuous multi-milestone progression, bounded parallelism, Executor/Tester separation, strategic escalation, lane/worktree isolation, integration ownership, recovery, and no capability-preflight policy switching;
- identify M01 implementation dependencies/ordering for the subsequent namespace-foundation Card;
- persist the result as `docs/audits/CODEX_ONLY_M01_BASELINE_MATRIX.md`.

### Excluded

- creating or editing `workflow/codex_only/` production contracts;
- changing `workflow/CONTEXT_ROUTING.md`;
- changing existing `workflow/chatgpt_only/` behavior;
- deleting or rewriting legacy/shared contracts;
- defining runtime session/model/profile/invocation mechanics;
- implementing bounded-parallel schema/state semantics beyond recording the required future delta.

## Acceptance

- every current `workflow/chatgpt_only/` file appears exactly once in the policy-local parity inventory;
- every relevant legacy evidence family named by `CO-REQ-027` is represented;
- all nine useful legacy properties enumerated by `CO-REQ-026` have explicit preserve/adapt/reject dispositions with target milestone/contract ownership;
- the matrix distinguishes unchanged lifecycle semantics from Codex-specific deltas and genuinely common candidates;
- no row treats legacy shared execution contracts as the architectural base;
- the matrix records that root routing cutover is deferred until the dedicated namespace is complete;
- the matrix records no Project Workflow ownership of runtime-only worker/session identifiers;
- the output is sufficient for Execution Prep to contract the next M01 namespace-foundation Card without redoing discovery.
